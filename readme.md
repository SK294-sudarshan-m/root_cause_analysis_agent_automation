# JSON Claim Summary Analyzer

## Overview

JSON Claim Summary Analyzer is a Python utility that processes one or multiple insurance claim JSON files and generates a consolidated Excel report for claim review and analysis. The tool recursively extracts the required information from nested JSON structures, filters valid records, groups semantically similar claim summaries, and ranks the resulting categories based on their frequency.

## Features

* Processes a single JSON file or multiple JSON files from a directory.
* Recursively searches nested JSON structures to extract required fields.
* Filters and processes only records where `case_verdict = 0`.
* Generates a consolidated Excel report containing claim information.
* Groups semantically similar claim summaries into meaningful categories using sentence embeddings.
* Creates specific reason categories based on the underlying issue rather than exact text matching.
* Ranks categories according to the number of occurrences.
* Works completely offline without requiring any API keys or external services.

## Output

The generated Excel report contains the following columns:

| Column                      | Description                                                                                                                                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **AL numbers**              | Unique claim/case number extracted from the `case_number` field.                                                                                                             |
| **reason**                  | Summary extracted from the `summary` field describing why the claim was flagged for manual review.                                                                           |
| **Case Verdict**            | Verdict extracted from the JSON. Only records with `case_verdict = 0` are processed.                                                                                         |
| **reason_category**         | A semantic category generated by comparing similar claim summaries. Similar review reasons are grouped together under a common category while preserving the specific issue. |
| **reason_category_count**   | Total number of claims belonging to the same semantic category.                                                                                                              |
| **reason_category_ranking** | Rank assigned to each category based on its occurrence count, where **1** represents the most frequently occurring category.                                                 |

## Dependencies

Install the required Python packages:

```bash
pip install pandas
pip install numpy
pip install sentence-transformers
pip install scikit-learn
pip install openpyxl
pip install torch
```

Alternatively, install all dependencies at once:

```bash
pip install pandas numpy sentence-transformers scikit-learn openpyxl torch
```

## Usage

1. Place the input JSON files inside the configured input directory.
2. Run the script:

```bash
python case_verdict_most_common_reason_finder.py.py
```

3. The generated Excel report (`case_summary.xlsx`) will contain the extracted claim information along with semantic categorization, category count, and category ranking.
